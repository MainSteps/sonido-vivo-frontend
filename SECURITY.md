# Seguridad

Sonido Vivo es un frontend académico. No implementa autenticación real ni debe almacenar información sensible.

## No subir al repositorio

- Contraseñas o datos personales reales.
- Tokens, claves privadas o credenciales de servicios.
- Archivos `.env` con secretos.
- Exportaciones de bases de datos reales.

El inicio de sesión de esta etapa debe usar datos simulados. Si accidentalmente se publica un secreto, avisa a Diego por un canal privado; no lo copies en un Issue público. El secreto deberá revocarse, aunque el archivo se elimine después.
