# Pruebas de resoluciones y navegadores de Michel

## Objetivo

Verificar que las páginas de registro, acceso, contacto y administración de usuarios de Sonido Vivo puedan utilizarse en los tamaños de pantalla acordados, sin desbordes ni controles inaccesibles.

## Resoluciones objetivo

| Dispositivo | Ancho | Alto usado en la prueba | Estado inicial |
| --- | ---: | ---: | --- |
| Teléfono móvil | 360 px | 800 px | Pendiente |
| Tableta | 768 px | 1024 px | Pendiente |
| Computador de escritorio | 1280 px | 800 px | Pendiente |

## Navegadores objetivo

| Navegador | Sistema | Estado inicial |
| --- | --- | --- |
| Google Chrome | macOS | Pendiente |
| Safari | macOS | Pendiente |

## Páginas que se revisarán

- Registro.
- Inicio de sesión.
- Contacto.
- Listado de usuarios.
- Crear usuario.
- Ver usuario.
- Editar usuario.

En cada combinación se revisará el ancho del contenido, la disponibilidad de enlaces, campos, selectores y botones, y la aparición de errores de JavaScript.
